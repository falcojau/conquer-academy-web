# Conquer Academy - Technology Training Platform

A comprehensive multi-page website built to showcase semantic HTML5 best practices. This project simulates a real-world technology academy platform with dedicated sections for courses, news, and user management.

## 🚀 Features
* **Multi-page Architecture:** Organized structure with dedicated directories for Blog and Courses content.
* **Semantic HTML5:** Full use of structural tags for high accessibility and SEO standards.
* **User Flow:** Includes functional layouts for Registration, Login, and Contact forms.
* **Legal Compliance:** Includes a dedicated page for Privacy Policies.

## 📂 Project Structure
* `/blog`: Article and news pages.
* `/cursos`: Detailed course information.
* `/media`: All visual assets and images.
* `index.html`: Main landing page.
* `about_us.html`, `contacto.html`, `registro.html`, `login.html`: Core platform pages.
* `politicas.html`: Legal information page.

## 🛠️ Technologies Used
* **HTML5:** Semantic markup.
